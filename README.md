# Gallifrey Station

The personal site of Orbit Mechanic (Bob Clark) — games, tools, and simulations built in low orbit.

Live at [orbitmechanic.github.io](https://orbitmechanic.github.io/).

## Stack

Static HTML, CSS, and vanilla JavaScript. The hero loop is rendered in Godot and shipped as WebM/MP4 with a WebP poster.

## Local preview

```sh
python3 -m http.server 8123
```

Then open <http://localhost:8123/>.

## Deploy

Push to `master`. GitHub Pages serves the repository root.
